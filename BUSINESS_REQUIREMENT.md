# Business Requirements & Scope

## Problem Statement
Knowledge workers often work for long uninterrupted periods and beyond defined work hours. Existing tools rely on static reminders, which are frequently ignored.

## Objective
Build a browser extension that:
- Observes high-level activity signals
- Uses AI-assisted decision logic
- Delivers context-aware reminders
- Demonstrates system design and collaboration

## In Scope
- Browser extension (Manifest v3)
- Active usage and time-of-day tracking
- AI-assisted decision service
- Dockerized backend
- Notification-based feedback

## Out of Scope
- User accounts or authentication
- Persistent data storage
- Analytics dashboards
- ML model training
- Fine-grained tracking (URLs, keystrokes)

## Success Criteria
- Extension and AI service integrate correctly
- Docker service runs with one command
- Notifications trigger based on AI decisions
- Clear documentation and collaboration history
