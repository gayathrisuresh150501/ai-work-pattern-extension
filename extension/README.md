# Browser Extension

## Purpose
Collect high-level, privacy-safe activity signals and display reminders based on AI decisions.

## Responsibilities
- Track active usage duration
- Capture time-of-day context
- Aggregate signals
- Call AI decision service
- Display notifications
- Apply fallback logic

## Technologies
- Chrome Extension (Manifest v3)
- JavaScript / TypeScript
- Chrome APIs (tabs, alarms, notifications)

## Notes
- No content scripts
- No tracking of URLs or page content
- Minimal permissions by design
